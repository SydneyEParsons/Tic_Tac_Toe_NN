# Tic_Tac_Toe_NN Description:
Using Keras to analyze the loss and accuracy of training the model on the game Tic Tac Toe.

# Dataset:
- Source: UCI Machine Learning Repository
- Author: David Aha
- Link to site: https://archive.ics.uci.edu/dataset/101/tic+tac+toe+endgame
- Citation in APA: Aha, D. (1991). Tic-Tac-Toe Endgame [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5688J.

# Required Imports:
- Python
- NumPy
- Pandas
- Keras
- Matplotlib
- Scikit-Learn
- TensorFlow

# Instructions:
- Copy the code from tic_tac_toe_keras.ipynb
- Download the dataset from the link: https://archive.ics.uci.edu/dataset/101/tic+tac+toe+endgame
- Install any required imports to your virtual environment
- Then you are all set to run your script! :)
